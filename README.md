# SiteScan

Локальный SEO-аудитор на Astro. Сканирует до 100 страниц одного сайта, группирует проблемы по приоритету и формирует PDF-отчёт на русском языке.

## Возможности

- доступность страниц, HTTP-статусы, HTTPS и серверные задержки;
- `robots.txt`, sitemap и sitemap-index (включая `.xml.gz`), canonical, meta robots и индексируемость;
- title, description, H1/H2, язык, viewport и объём контента;
- до 10 целевых ключевых фраз: частота, плотность, title, description, H1, URL и первые 100 слов;
- автоматический частотный словарь и популярные внутренние анкоры;
- полный анализ контента каждой страницы: тип и поисковый интент, полнота, структура, читабельность, уникальность, опыт, экспертность, доверие, ключевые фразы и AI-цитируемость;
- объяснимый контентный балл, норматив объёма по типу страницы, время чтения, длинные предложения, факты/числа, риск повторов, сильные/слабые стороны и персональные рекомендации;
- более 20 расширенных контентных проверок на страницу: вступление, интент, заголовки, абзацы, CTA, ссылки, источники, опыт, авторство, свежесть, конкретика, переспам, визуальные доказательства и соответствие Schema.org;
- отдельный безопасный промпт для Codex у каждой непройденной проверки и общий промпт исправления всей страницы;
- оценка готовности контента к цитированию в AI-ответах;
- дубли title, description, H1 и вероятно похожие страницы;
- внутренний граф сайта: глубина URL, входящие ссылки и поиск сиротских страниц;
- полные цепочки редиректов, параметрические URL и вероятные ловушки бесконечного обхода;
- аудит качества sitemap: ошибочные, неиндексируемые и перенаправляемые URL, валидность и достоверность `lastmod`, будущие/массово одинаковые даты, `changefreq` и `priority`;
- распределение HTTP-ответов, эффективность обхода, средний ответ и p95;
- эвристические риски Core Web Vitals для LCP, INP и CLS без подмены полевых данных;
- пакетная проверка до 500 внутренних/внешних ссылок со статусами, источниками и редиректами;
- изображения, alt, размеры, риск CLS, fallback `src` для `srcset/picture`, стабильность URL и информативность имён файлов;
- видео, poster/thumbnail и наличие релевантного `VideoObject`;
- битые ссылки, пустые/общие анкоры, небезопасные HTTP-ссылки;
- JSON-LD Schema.org с проверкой обязательных полей, актуальности Google rich results, WebSite на главной, Open Graph, Twitter Cards и hreflang;
- meta/X-Robots-Tag: конфликты индексации, `nosnippet`, `max-snippet`, `max-image-preview` и другие ограничения превью;
- даты публикации/обновления: ISO 8601, будущие значения и конфликт `dateModified`/`datePublished`;
- размер HTML и DOM, число скриптов, пустой JavaScript app shell, версии JS/CSS, сжатие, актуальный формат favicon и доступность форм;
- эвристика масштабированных шаблонных страниц под варианты запросов;
- security headers, информационный статус `llms.txt` без SEO-штрафа и блокировки AI-краулеров;
- оценки по девяти направлениям, список исправлений и таблица страниц;
- официальный PageSpeed Insights/Lighthouse lab-тест для mobile и desktop;
- локальный импорт CSV из Google Search Console и поиск страниц/запросов с потенциалом роста;
- интерактивный robots.txt tester для Googlebot, Bingbot и AI-ботов;
- PDF, JSON и CSV-экспорт, включая архитектуру, sitemap и битые ссылки;
- пошаговое решение для каждой найденной проблемы;
- отдельный готовый промпт для Codex по каждой ошибке;
- общий приоритетный Codex-план без повторов: одинаковые проблемы сводятся к одной первопричине со списком всех URL, планом исправления и обязательным повторным аудитом; план скачивается как `.md` с доменом сайта в имени файла;
- локальная история последних 10 полных аудитов с открытием и повторным запуском в один клик;
- автоматическое сравнение оценки, ошибок и охвата с прошлой проверкой домена;
- постраничный change tracking: метаданные, индексируемость, объём, оценка, новые и исчезнувшие проблемы;
- автоматические тематические кластеры и карта релевантных страниц;
- карта интентов по заданным ключам: вероятный primary URL, конкурирующие страницы, риск каннибализации и отдельный промпт ручной проверки SERP;
- content gap по импортированному JSON-аудиту конкурента;
- визуальный Schema Inspector и базовый аудит доступности для каждой страницы;
- SVG-карта внутренних ссылок, рекомендации новых связей и готовые Codex-промпты;
- пользовательские правила качества с безопасным allowlist-синтаксисом и локальным хранением;
- локальный анализ Common/Combined server access logs, поисковых/AI-ботов и проблемных HTTP-ответов;
- сравнение исходного HTML с сохранённым отрисованным DOM после выполнения JavaScript;
- финальный скриншот реального рендера из Lighthouse;
- локальный мониторинг по расписанию, пока вкладка SiteScan открыта;
- повторный аудит исправлений в один клик и сравнение с предыдущим полным отчётом;
- группировка однотипных проблем по шаблону и URL, чек-лист исправлений, поиск, сортировка страниц и фильтры, сохраняемые в URL;
- подробная диагностическая карточка каждой просканированной страницы;
- потоковый прогресс реального обхода и отмена активного аудита без перезагрузки интерфейса;
- защита от SSRF: локальные, приватные и служебные IP блокируются.

## Запуск

Нужен Node.js 22.19 или новее и pnpm.

```bash
pnpm install
pnpm dev
```

Откройте `http://localhost:4321`. Для production-сборки:

```bash
pnpm build
node dist/server/entry.mjs
```

PageSpeed API можно использовать без ключа для редких ручных запусков. Для стабильной квоты задайте переменную окружения `PAGESPEED_API_KEY` перед запуском приложения.

Компактная история и отметки исправлений сохраняются в `localStorage`, полные отчёты — в IndexedDB текущего браузера. На сервере история не хранится. HTML-эвристика скорости не заменяет полевые Core Web Vitals; PageSpeed-кнопка показывает отдельный лабораторный Lighthouse-тест.
